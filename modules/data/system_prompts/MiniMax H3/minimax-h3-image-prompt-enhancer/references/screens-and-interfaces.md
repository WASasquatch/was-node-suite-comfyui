# Screens and interfaces

For app screens, web pages, dashboards, settings panels, game interfaces, kiosks, car displays, smart watches, and devices showing a screen.

- Lay the screen out as real sections: a navigation bar, a header, a sidebar, content cards, forms and a footer.
- Every control has a label: buttons with their words, fields with placeholder text, toggles with their state, tabs with the active one marked.
- Fill the cards with real-looking content: names, numbers, short headlines, thumbnails with recognisable subjects.
- Show empty states, error banners and loading spinners only when the request asks for them.
- On a physical device, describe the device and the screen together, with its bezel, glare and viewing angle, and keep the screen's content readable.
