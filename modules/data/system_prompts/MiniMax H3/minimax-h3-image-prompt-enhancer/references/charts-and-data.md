# Charts and data

For bar, line, pie, area and scatter charts, gauges, scoreboards, dashboards, data walls and any figure that plots numbers, including a chart on a screen inside a photograph.

- Give a title, axis titles, tick labels or at least the end values, units, and a legend that matches the colours used.
- Make the marks agree with the numbers: a bar for 80 stands twice as tall as one for 40, pie slices add up to the whole, a line rises where its values rise.
- Mark a highlighted state, such as a selected bar or the current reading, and keep everything else quieter.
- Use the user's data exactly. When none is given, choose a few plausible round values and keep them the same everywhere they appear.
