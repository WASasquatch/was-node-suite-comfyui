# Planning a designed page

For anything made to be read: posters, flyers, covers, cards, boards, infographics, diagrams, menus, packaging, web pages, app screens, slides, résumés and documents.

- Before writing, divide the canvas into regions in reading order: title band, subtitle, main image, side panel, row of cards, chart area, footer. Most pages have three to eight.
- For each region, write where it is, the text it carries word for word, what it shows, what it is for or how it connects to its neighbours, and how it is styled.
- Never leave a region vague. Words such as icons, details, supporting graphics or information say nothing; name the icon and its label, the figure and its value.
- A finished design carries the small parts its kind usually has: a subtitle, a legend, units, a short tip, a credit line, a logo placeholder. Add a few when they help, as short labels rather than paragraphs.
- Describe the system holding it together: grid, margins, alignment, type hierarchy, palette in named colours, background texture, and how much empty space is left.
- These captions may run well past 350 words. Every region deserves its own sentences.
