# Posters, covers and packaging

For posters, book and magazine covers, album art, flyers, event bills, film one-sheets, labels, boxes, bottles, cans and other packaging.

- Build a clear type hierarchy: one headline, a subtitle or tagline, smaller supporting copy, and fine print where it belongs, such as dates, venue, credits, ingredients or weight.
- Use one hero image for each thing being sold or shown, unless the user wants a group. Say how the hero is cut out, framed or bled off the edge.
- Name the graphic devices: badges, stickers, borders, rules, stripes, halftone dots, paper texture, foil, spot gloss.
- Add a QR code, barcode or logo placeholder only when the request calls for one.
- Packaging is an object as well as a design. Name its material and shape (a matte paperboard carton, a frosted glass bottle with a cork stopper), which faces are in view, and how the light falls across them.
