# Matching panels and multiple views

For anything shown more than once in one image: before and after, a floor plan beside an interior render, a blueprint beside a product shot, a map beside a street view, comic strips, storyboards, step-by-step sequences, turnarounds and split screens.

- Keep one inventory. The same walls, doors, windows, furniture, parts, colours and labels appear in every panel that shows them, in the same places relative to each other.
- A before and after changes only what the request changes; everything else stays put.
- Say where the render's camera stands on the plan, or which side of the product each view shows.
- Never add a major object to one panel that its partner lacks.
- Number or title the panels so their order is clear, and keep borders and gutters even.
