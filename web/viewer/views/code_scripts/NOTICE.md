# Prism, vendored

Syntax highlighting for the Content Viewer's code view. The files are read as text and inlined
into the view's sandboxed frame.

- Upstream: <https://github.com/PrismJS/prism>
- Version 1.29.0, npm `prismjs@1.29.0`
- Licence: MIT, retained in `LICENSE` beside this file

## Files taken from upstream

Every file is byte for byte the published file, renamed from `.js` to `.txt`.

| File | Upstream file |
|---|---|
| `prism.min.txt` | `prism.min.js`, the build of core with markup, css, clike and javascript |
| `prism-bash.min.txt` | `components/prism-bash.min.js` |
| `prism-css.min.txt` | `components/prism-css.min.js` |
| `prism-javascript.min.txt` | `components/prism-javascript.min.js` |
| `prism-json.min.txt` | `components/prism-json.min.js` |
| `prism-markup.min.txt` | `components/prism-markup.min.js` |
| `prism-python.min.txt` | `components/prism-python.min.js` |
